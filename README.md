
•	Project Information
ContactManager is a Java-based application designed to store and manage personal or professional contact details. It allows users to add, search, update, and delete contacts in an organized way. The project is built with Core Java concepts and is designed for scalability, so it can be extended to support databases, graphical interfaces, and advanced features.

•	Project Overview
The primary goal of ContactManager is to provide an efficient way to handle contacts without relying on third-party applications. Starting with a console-based implementation, the application demonstrates key programming concepts such as object-oriented design, data handling, and modular architecture. It is designed to support different user roles, each having a different level of access and control.

•	Features
- Add and store new contacts with details such as name, phone number, email, and address
- Search for contacts by name, phone number, or email
- Update existing contact information
- Delete contacts from the system
- Role-based access (User, Guest, Admin) for controlled functionality
- Modular design that can be extended with databases or a graphical interface

• Role-Based Functionality

•	Guest
- Can view limited features such as demo data
- Can explore sample contacts for understanding how the system works
- Cannot add, modify, or delete contacts

•	User
- Can register and log in to the system
- Can add new contacts with detailed information
- Can search, update, and delete their own contacts
- Can view their full contact list
- Has access to personalized contact management

•	Admin
- Can manage all users and their contact data
- Can view, update, or delete contacts across all users
- Can monitor and maintain data integrity
- Responsible for handling backups and overall system maintenance
- Can generate reports of user and contact activity

•	Future Enhancements
- Database integration for persistent storage
- Graphical user interface using JavaFX or Swing
- Contact grouping and categorization (family, friends, work, etc.)
- Import and export contacts in CSV or VCF formats
- Multi-user authentication and secure login system
